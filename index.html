01　準備出題內容

第一次使用？先下載 Gemini Skill

下載 ZIP，在 Gemini「自訂／Customize → Skills → 建立 → 上傳」匯入。ZIP 內已有根目錄 SKILL.md，無須解壓縮。介面與可用性以您的帳號為準。

下載 Gemini Skill ZIP SKILL.md

找不到 Skills 也可直接使用下方完整提示詞，在一般 Gemini 對話出題。Google 官方操作說明 ↗

請在自己的 Gemini 對話附上 PDF、Word 或圖片，再貼入本站產生的提示詞。本網站不讀取或上傳附件，也不需要 API 金鑰。若 Gemini 無法讀取檔案，請改用清晰圖片、PDF 或貼上文字。

開啟 Gemini ↗

使用已匯入的 pagamo-question-builder Skill，或直接貼上提示詞。附件模式請記得在同一則 Gemini 訊息附上檔案。網站不會自動操作您的 Gemini。超過 20 題建議分批生成，再於右側追加匯入。

02　貼回 Gemini 生成結果

取代匯入時會套用 JSON 中的科目等設定；追加時保留目前設定。格式錯誤的題目會標示供修改，不會截短解說或自動改答案。

可先載入示範題，試試編輯與 Excel 匯出。
